# Agents

Connect AKM to your AI assistant so it can discover capabilities, load relevant knowledge, and remember what it learns.

- [Use AKM With Any Agent](../guides/use-with-any-agent.md) — Add AKM to your assistant's instructions.
- [Agent Install Guide](agent-install.md) — Install and configure AKM through an agent.
- [Headless Install](../guides/recipes/headless-install.md) — Set up AKM without interactive prompts.

Run `akm help agents` for the compact agent guide, or `akm help agents --full` for the complete CLI guide.
